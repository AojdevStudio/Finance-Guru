# Security policy

## Supported versions

Security fixes target the latest release. Update older versions to the latest
[Finance Guru release](https://github.com/AojdevStudio/Finance-Guru/releases).

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/AojdevStudio/Finance-Guru/security/advisories/new)
to contact the maintainers. Do not post security vulnerabilities in public issues.

Include the affected version, the impact, and steps to reproduce the problem.
Use synthetic data in examples. Do not include credentials or private financial
data in the report.
